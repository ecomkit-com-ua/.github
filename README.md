# ecomkit-github-profile

Вміст репозиторію **`ecomkit-com-ua/.github`** — спеціального репозиторію, з якого GitHub
бере профіль організації. Файл `profile/README.md` рендериться на сторінці
`github.com/ecomkit-com-ua` над списком репозиторіїв.

Тут він лежить окремим проєктом, щоб було видно, що саме публікується: сторінка організації
публічна, і все з `profile/README.md` бачить будь-хто.

## Що всередині

- `profile/README.md` — власне профіль. Двомовний: англійський абзац для тих, хто прийшов
  із каталогів MCP-серверів, далі українською для власників магазинів.

## Публікація

Репозиторій має називатись рівно `.github` і бути **публічним** — інакше GitHub профіль
не підхопить.

```
gh repo create ecomkit-com-ua/.github --public --source=. --push --description "Профіль організації"
```

Далі кожна зміна — звичайний `git push`; сторінка оновлюється миттєво.

## Що сюди не класти

Нічого, крім тексту профілю. Це не місце для нотаток, чернеток чи внутрішніх документів:
репозиторій `.github` публічний за визначенням, а його README — перше, що бачить людина,
яка перейшла з каталогу або з посилання в спільноті.
