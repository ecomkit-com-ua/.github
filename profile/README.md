## ecomkit

**English:** open-source tooling for Ukrainian e-commerce stores, by
[Sergiy Troitskiy](https://ecomkit.com.ua) — a product manager who launches, fixes and runs
online stores on Horoshop, WooCommerce and Shopify. Everything here is MIT licensed and free
to use. Documentation is in Ukrainian, because the people who run these stores read Ukrainian.

---

Тут лежать інструменти, які я пишу для власної роботи з інтернет-магазинами й надаю
відкритими. Без оплати, без реєстрації, без «залиште пошту, щоб завантажити».

### Що є зараз

- **[horoshop-mcp](https://github.com/ecomkit-com-ua/horoshop-mcp)** — підключає ШІ-асистента
  до магазину на Хорошопі. Замовлення, каталог, ціни, залишки й покупці — звичайною мовою
  в чаті, замість кліків в адмінці. Працює на вашому комп'ютері, режим лише читання
  за замовчуванням.
  [Пояснення без технічних деталей →](https://ecomkit.com.ua/instrumenty/?utm_source=github&utm_medium=org-profile&utm_campaign=horoshop-mcp)
